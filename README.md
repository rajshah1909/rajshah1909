## Featured Engineering Projects

### 01 — [FOMC Yield Curve Prediction](https://github.com/rajshah1909/ds-project)
*Financial NLP + Predictive Modeling*

Analyzes Federal Reserve communication and macroeconomic data to model short-term Treasury yield movements, validated walk-forward against a macro-only baseline across 591 FOMC statements (1994–2024).

`NLP / FinBERT` `XGBoost / Predictive Modeling` `Financial Time-Series`

### 02 — [RU-PATH](https://github.com/rajshah1909/ru-path)
*Backend Assistant for Rutgers Parking & Transit*

Application that resolves Rutgers parking and transit questions across 4 campuses — a Flask API routes each query through intent detection and structured-data matching before handing context to DeepSeek for a natural-language answer.

`Flask REST APIs` `LLM Integration (DeepSeek)` `Intent Routing & Data Modeling`

### 03 — [EvacAI](https://github.com/milipatel1309/EvacAI)
*AI-Powered Disaster Preparedness Platform*

Disaster-preparedness application combining geolocation, live weather and alert data, a risk-scoring model, and IBM watsonx/Granite-generated guidance — built as a 4-person team for the IBM Z × UNSA Hackathon, with a SwiftUI iOS client and web client. *(Team repo, hosted under a teammate's account.)*

`SwiftUI / iOS Development` `FastAPI / Application Backend` `IBM watsonx / Granite`
